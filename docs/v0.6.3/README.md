## 一句话结论

长会话不再需要人工反复输入"继续"：请求级退避改为可配置分级阶梯，轮次级失败改为**等待后重发整轮**（默认 6 次），Goal Mode 支持 `completion_signal` 完成收口。全部落在 `managed-ga/patches/1000-managed-interruption-resilience.patch`，不触碰 GUI / Rust。

## 不在本版本范围

- 模型配置界面新增 `retry_schedule` / `turn_retry_max` 的可视化输入控件（引擎已支持读键，UI 未提供入口，见技术方案 §7）。
- 中断根因（上游 503）本身的可用性治理。
